# personal-ai 部署手册

> 零第三方依赖：装好 Python 3.9+ 就能跑，**不需要 pip install 任何东西**。
> 密钥只走环境变量 / 本机网关，不落盘、不进任何仓库。
> 🔴 诚实口径：本文标 ✅ 的步骤是 2026-10-28 实测过的；标 ⚠️ 的是**未实测**（写明原因）。

## 一条最短路径（Windows，✅ 实测）

```
双击桌面「启动个人AI.bat」→ 浏览器自动打开 http://127.0.0.1:8787
```
（脚本内容 = 起 OmniRoute 网关 `--daemon` + `python scripts/start_local.py` + 开浏览器）

命令行等价（✅ 实测）：
```bat
omniroute serve --no-open --daemon
python scripts/start_local.py
```

## Windows（✅ 实测）

1. 装 Python 3.9+（本机 3.11；3.13 也在 CI 矩阵里跑过测试）
2. 离线模式（不调用真实模型，零配置）：
   ```
   python -m personal_ai --serve
   ```
   打开 http://127.0.0.1:8787 —— 发消息、看流式回复、时间轴 UI 都能用
3. 真实模型（走本机 OmniRoute 网关）：
   ```
   omniroute serve --no-open --daemon
   python scripts/start_local.py
   ```
4. 查看当前配置 / 单次问答验证真实调用链：
   ```
   python -m personal_ai --status
   python -m personal_ai --once "你好"
   ```

## 手机 / 局域网访问（✅ 服务端实测，手机端待设计者配合）

**零代码改动**，两个环境变量：

```bat
set PAI_HOST=0.0.0.0
set PAI_PORT=8787
python -m personal_ai --serve
```

- 实测（10-28）：`PAI_HOST=0.0.0.0` 后服务绑定 `0.0.0.0:8787`（netstat 确认），本机 HTTP 200
- 手机连**同一个 WiFi**，浏览器打开 `http://<电脑局域网IP>:8787`
  （查 IP：`ipconfig` → IPv4 地址；macOS/Linux：`ip addr` / `ifconfig`）
- 🔴 只做局域网，**不做公网暴露**（打洞/域名/证书属于网络+外部账号操作，由设计者手动做一次）
