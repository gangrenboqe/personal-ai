## 2026-10-10

- **补上单元测试层（31 项）**：新增 `tests/test_units.py`，只测纯函数，毫秒级、不起服务不联网。
  两层测试分工明确：单元测试验"函数算得对不对"，冒烟验"整体能不能跑"。
  覆盖：Provider 抽象与来源链拼接、离线兜底必须自我标注、URL拼接的幂等性、
  **密钥绝不出现在对外快照里**、环境变量写成乱码时的回落、存储层增删改查与非法状态回落、
  以及上下文过滤的回归测试。
- **单元测试当场抓出一个真 bug 并修掉**：`list_messages(limit=N)` 之前取的是
  **最早** N 条（`ORDER BY id ASC LIMIT N`），导致对话变长后拼上下文会拿到开头的老消息、
  **用户刚说的那句话不在里面**。已改为取最近 N 条再按时间正序返回。
  这条 bug 靠人看代码基本发现不了，是测试逼出来的。
- **会话下拉"白底白字"修复**：`select` 设了接近白色的文字，但从未给 `option` 定色；
  Windows 原生下拉按浅色弹出 → 白字落白底，只有悬停高亮才看得见。
  修法：`:root` 加 `color-scheme: dark`，`.session-select option` 显式深底浅字。
  验证方式：用 Chrome 无头读回浏览器**实际计算值**（底 `rgb(11,16,23)` / 字 `rgb(243,246,251)`），不是靠截图猜。
- **32 项冒烟接入 CI**：新增 `.github/workflows/smoke.yml`，
  push / PR 时在 Ubuntu + Windows、Python 3.11 / 3.13 上自动跑，现为 31 + 32 两层。
- **启动脚本加逐步日志**：`.bat` 每一步写入 `%LOCALAPPDATA%\personal_ai\launch.log`，
  用于定位"窗口自行消失"（原因尚未确认，日志是取证手段）。
- **文档**：`DECISIONS.md` 增补 D9（不做鉴权的前提是只监听本机，两者不能单独改）；
