# 设计决策记录（DECISIONS）

> 记录"为什么这么选"，以及**放弃了什么**。临场被问到时能直接对着说，不用现编。
> 格式：决策 → 理由 → 放弃的备选 → 代价。

---

## D1 · 零第三方依赖：只用 Python 标准库

**决策**：只用 `http.server`（网页服务）、`sqlite3`（存储）、`urllib`（发请求）。不装 Flask / FastAPI / requests。

**理由**
- 依赖越少，越能讲清每一行为什么这么写——这是本项目最大的答辩价值。
- `pip install` 在任何机器上都可能失败；标准库不会。
- 审计面小：整个项目可以被一个人完整读完。

**放弃的备选**：Flask（路由/模板好用）、FastAPI（自带 OpenAPI 文档）。

**代价**：路由要手写 `if path == ...`；没有自动生成的接口文档；表单解析、JSON 处理都得自己来。
这些代价是**故意承担的**。

---

## D2 · Provider 注册表：换模型供应商只改一处

**决策**：所有模型供应商实现同一个基类，用一个注册表 `@register` 收集；上层按名字取。

**理由**：业务代码不该知道回答来自哪家。换供应商 = 新增一个子类，业务代码零改动。

**放弃的备选**：在业务代码里 `if provider == "openai": ... else: ...`（一旦加第三家就变成面条）。

**代价**：多一层间接，读代码时要跳转一次。

---

## D3 · 每条回答都存调用链（chain）

**决策**：回答里除了内容，还存 `provider / model / chain`，并且界面上直接显示。

**理由**：一眼看出这条回答是真模型还是离线兜底。**不伪装**比"看起来能用"重要。

**放弃的备选**：只存内容（更简单，但无法自证）。

**代价**：数据库多三个字段，接口返回体变大。

---

## D4 · mock（离线兜底）必须显式标注

**决策**：离线兜底的回答以 `[mock]` 开头，调用链显示 `mock → mock-offline`，界面提示"未产生真实模型调用"。

**理由**：一个会**主动承认自己没调模型**的系统，比一个静默降级的系统可信。

**代价**：无。

---

## D5 · 超时 180 秒、重试 2 次，且只对特定错误重试

**决策**：`timeout=180s`，`retries=2`；**只对超时 / 5xx / 429 重试**，4xx 一律不重试。

**理由**：上游冷启动实测 50–115 秒，60 秒超时必然失败。
4xx 是客户端错误（参数错、鉴权错），重试只会浪费时间并掩盖真实问题。

**代价**：单次失败最长要等 3 × 180 秒才有最终结论。

---

## D6 · 密钥只从环境变量读

**决策**：`config.py` 里密钥**只**从环境变量读，不写进代码、不落盘、不进 commit。

**理由**：密钥一旦进过 git 历史，撤销代价极高。

**代价**：每次启动要设环境变量（用 `scripts/start_local.py` 自动处理）。

---

## D7 · 单文件 SQLite 存储

**决策**：`sessions` + `messages` + `tasks` 三张表，落本地单个 `.db` 文件。

**理由**：数据自有；备份就是拷一个文件；不需要起数据库服务。

**放弃的备选**：JSON 文件（并发写不安全、查询麻烦）、外部数据库（破坏零依赖）。

**代价**：并发写能力有限（本项目单机单人使用，可接受，**已知未做**）。

---

## D9 · 不做登录鉴权（因为不开放）

**决策**：HTTP 服务不做任何登录 / Token 鉴权，只监听 `127.0.0.1`（本机回环地址）。

**理由**：不出本机的服务，鉴权带来的复杂度远大于收益。
曾经实现过局域网 / 手机访问（`--host 0.0.0.0`），后来**因为安全与设计取舍撤销了**，
相关代码与文档一并 revert —— 不开放，所以不做鉴权，这两件事是对等的。

**放弃的备选**：加一层简单密码 / Token（真要开放访问时**必须**补上）。

**代价**：**一旦改成对外监听，这就是个洞**。所以这条和"只监听本机"必须绑定，
不能单独改其中一个。

---

## D8 · Windows 启动脚本必须 GBK + CRLF

**决策**：`.bat` 用 GBK(936) 编码、CRLF 换行，**绝不 UTF-8**，绝不加 `chcp 65001`。

**理由**：中文 Windows 的 cmd 默认 GBK。UTF-8 的 bat 会被按错误字节数解析，
出现"命令语法不正确"然后**窗口一闪就关**——排查成本极高（实测踩过）。

**代价**：脚本里不能写 emoji 等特殊字符。
